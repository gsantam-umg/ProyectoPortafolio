Proyecto 1 - Limpieza de un case de computadora

Este proyecto consistió en realizar la limpieza interna de un case de computadora, siguiendo un procedimiento adecuado y seguro para evitar daños en los componentes electrónicos. Durante el proceso, se identificaron y analizaron cada uno de los elementos principales del equipo, tales como la tarjeta madre, la memoria RAM, el disco duro, la fuente de poder y los ventiladores. Asimismo, se utilizaron herramientas específicas como brochas, aire comprimido y paños antiestáticos para eliminar el polvo acumulado.

Además de la parte práctica, se llevó a cabo una investigación sobre la función de cada componente, su importancia dentro del funcionamiento del sistema y los posibles problemas que pueden surgir si no se les da el mantenimiento adecuado. Finalmente, se elaboró un informe detallado en el que se documentó paso a paso el procedimiento realizado, resaltando la importancia del mantenimiento preventivo para garantizar un mejor rendimiento, evitar fallas técnicas y prolongar la vida útil del equipo de cómputo.

Objetivos:

  • Identificar correctamente cada uno de los componentes internos de una computadora y conocer su función.
  • Aplicar técnicas adecuadas de limpieza utilizando herramientas seguras para el hardware.
  • Comprender la importancia del mantenimiento preventivo para mejorar el rendimiento y prolongar la vida útil del equipo.

A través de este proyecto aprendí a identificar correctamente las partes internas de una computadora y a comprender la función específica que cumple cada componente dentro del sistema. También desarrollé habilidades prácticas al manipular hardware de forma cuidadosa, aplicando técnicas adecuadas de limpieza sin poner en riesgo los dispositivos.

Asimismo, entendí la importancia del mantenimiento preventivo como una medida fundamental para evitar daños, mejorar el rendimiento del equipo y reducir costos de reparación a largo plazo. Este proyecto también me permitió ganar mayor confianza en el manejo de herramientas tecnológicas y fortalecer mis conocimientos en el área de informática, lo cual es esencial para mi formación académica y profesional.


Proyecto 2 - Instalación de Ubuntu/Linux

El proyecto consistió en la instalación del sistema operativo Ubuntu/Linux en una computadora, siguiendo de manera ordenada y precisa cada una de las etapas del proceso. Para facilitar la práctica y evitar afectar el sistema principal, se creó previamente una máquina virtual, la cual permitió simular un entorno real de instalación sin riesgos para el equipo.

inició con la configuración de la máquina virtual, asignando recursos como memoria RAM, almacenamiento y procesador. Posteriormente, se cargó la imagen del sistema operativo y se procedió con la instalación de Ubuntu/Linux dentro del entorno virtual. Durante este proceso, se realizaron particiones del disco, se seleccionaron configuraciones básicas como idioma, zona horaria y usuario, y se completó la instalación correctamente.

uno de estos pasos fue documentado mediante capturas de pantalla, con el fin de evidenciar el procedimiento realizado y facilitar su comprensión. Además, una vez finalizada la instalación, se ejecutaron comandos básicos en la terminal de Ubuntu/Linux para explorar el sistema, gestionar archivos y comprender el funcionamiento de la interfaz de línea de comandos. Finalmente, se elaboró un video explicativo en el que se mostró detalladamente todo el procedimiento realizado.

Objetivos:

  • Crear y configurar una máquina virtual adecuada para la instalación del sistema operativo.
  • Ejecutar correctamente el proceso de instalación de Ubuntu/Linux dentro del entorno virtual.
  • Utilizar comandos básicos en la terminal para gestionar el sistema y documentar el procedimiento realizado.

Gracias a este proyecto, aprendí a instalar un sistema operativo Linux desde cero, tanto en un entorno real como en una máquina virtual, comprendiendo cada una de las etapas necesarias para lograr una instalación correcta. También adquirí conocimientos sobre la creación y configuración de máquinas virtuales, lo cual es una herramienta muy útil para pruebas y aprendizaje en informática.

Asimismo, desarrollé habilidades en el uso de la terminal, ejecutando comandos básicos para la navegación dentro del sistema, la gestión de archivos y la interacción con el sistema operativo. Esto me permitió entender mejor el funcionamiento interno de Ubuntu y la importancia de los sistemas Linux en el ámbito tecnológico.

Por otro lado, fortalecí mi capacidad para seguir procesos técnicos de forma ordenada, prestar atención a los detalles y documentar adecuadamente cada paso realizado. Además, gané mayor confianza al trabajar con entornos virtuales y sistemas operativos, lo que contribuye a mi formación académica y profesional.


Proyecto 3 - Elaboración de cables de red

En este proyecto se realizó la elaboración y crimpado de cables de red tipo A y tipo B, utilizando conectores RJ45 y herramientas especializadas como la crimpadora, pelacables y probador de red. El proceso inició con la selección y preparación del cable UTP, retirando cuidadosamente la cubierta externa para exponer los pares de hilos internos sin dañarlos.

Posteriormente, se organizó el orden de los cables de acuerdo con las normas de cableado tipo A (T568A) y tipo B (T568B), asegurando que los colores estuvieran correctamente alineados antes de insertarlos en el conector RJ45. Luego, se procedió al crimpado utilizando la herramienta adecuada para fijar los pines del conector y garantizar una conexión segura.

Una vez finalizado el armado de los cables, se realizó una verificación utilizando un probador de red para confirmar que la transmisión de datos fuera correcta y sin fallas. Además, se documentó todo el procedimiento paso a paso y se explicó la función de cada tipo de cable dentro de las conexiones de red, destacando su uso en diferentes configuraciones como conexiones directas o cruzadas.

Objetivos:

  • Identificar y aplicar correctamente el orden de colores en los estándares T568A y T568B.
  • Utilizar herramientas de crimpado de manera adecuada para garantizar conexiones seguras.
  • Verificar el correcto funcionamiento de los cables mediante pruebas de conectividad.

Este proyecto me permitió comprender de manera más clara el funcionamiento de las conexiones de red y la importancia de una correcta elaboración de los cables para asegurar una transmisión de datos eficiente. Aprendí a identificar y aplicar correctamente el orden de colores en los estándares T568A y T568B, lo cual es fundamental en el área de redes.

Asimismo, desarrollé habilidades prácticas en el uso de herramientas de crimpado, mejorando mi precisión y cuidado al trabajar con componentes físicos. También entendí la importancia de verificar el funcionamiento de los cables mediante pruebas, lo que ayuda a prevenir errores en la instalación de redes.

Además, fortalecí mis conocimientos en conectividad y adquirí mayor confianza al realizar tareas técnicas, lo cual contribuye a mi formación en el área de informática y telecomunicaciones.


Proyecto 4 - Configuración de una red LAN

El proyecto consistió en la planificación y configuración de una red LAN (Local Area Network), conectando tres computadoras mediante un switch como dispositivo central. Se estableció una topología básica que permitió la comunicación entre los equipos dentro de un mismo entorno local.

Para lograr una correcta conectividad, se asignaron direcciones IP estáticas a cada computadora, asegurando que todas pertenecieran al mismo rango de red. Además, se implementaron conexiones tanto alámbricas como inalámbricas, organizadas en tres niveles en forma de cascada para simular una estructura más completa de red.

Finalmente, se habilitó el intercambio de archivos entre los equipos como prueba del funcionamiento de la red. Se realizaron pruebas de conectividad, como el uso del comando ping, para verificar que todos los dispositivos podían comunicarse correctamente entre sí.

Objetivos:

  • Configurar una red LAN funcional que permita la comunicación efectiva entre tres computadoras mediante el uso de un switch.
  • Asignar correctamente direcciones IP estáticas para garantizar la conectividad dentro de la red local.
  • Implementar el intercambio de archivos entre los equipos como prueba del correcto funcionamiento de la red.

Durante el desarrollo del proyecto, aprendí cómo funciona una red LAN y la importancia de una correcta configuración para garantizar la comunicación entre dispositivos. Comprendí los conceptos básicos necesarios para establecer una red local eficiente.

También adquirí conocimientos sobre la asignación de direcciones IP estáticas, incluyendo el uso adecuado de la máscara de subred y el gateway predeterminado. Esto me permitió entender cómo se identifican y comunican los equipos dentro de una red.

Además, fortalecí mis habilidades prácticas en la instalación y configuración de redes, comprendiendo el rol del switch en la transmisión de datos y la importancia de realizar pruebas de conectividad. Este proyecto me ayudó a aplicar la teoría en un entorno real y mejorar mi capacidad para resolver problemas relacionados con redes.

Proyecto 5 - Diseño de red LAN en Cisco Packet Tracer

Este proyecto se enfocó en el diseño y simulación de una red LAN (Local Area Network) utilizando el software Cisco Packet Tracer como herramienta principal. Se planteó la creación de una red doméstica adaptada a una casa de tres niveles, considerando la distribución de espacios y las necesidades de conectividad en cada área.

Durante el desarrollo, se implementaron distintos tipos de conexión, tanto alámbricas como inalámbricas, para garantizar una cobertura adecuada en toda la vivienda. Se configuraron dispositivos como routers, switches y equipos finales, organizando la red de manera lógica y funcional según cada nivel de la casa.

Finalmente, se elaboró un video explicativo en el cual se presentó el diseño de la red y su funcionamiento. En este material se detallaron las configuraciones realizadas, la estructura de la red y la forma en que los dispositivos se comunican entre sí dentro del entorno simulado.

Objetivos:

  • Diseñar y simular una red LAN funcional para una casa de tres niveles utilizando Cisco Packet Tracer.
  • Implementar diferentes tipos de conexión y configurar correctamente los dispositivos de red según las necesidades de cada área.
  • Explicar el funcionamiento de la red mediante un video, demostrando la correcta comunicación entre los dispositivos.

Gracias a este proyecto, aprendí a utilizar Cisco Packet Tracer como una herramienta fundamental para el diseño y simulación de redes. Esto me permitió comprender cómo planificar una red antes de implementarla físicamente.

También adquirí una mejor comprensión sobre la estructura y organización de una red LAN, incluyendo la distribución de dispositivos según el espacio y las necesidades de conectividad. Entendí la importancia de ubicar correctamente los equipos para lograr una red eficiente y estable.

Además, mejoré mi capacidad para identificar y resolver problemas de conectividad dentro de una red simulada. Este proyecto fortaleció mis habilidades técnicas y analíticas, permitiéndome proponer soluciones eficientes y aplicar conocimientos teóricos en un entorno práctico.


Proyecto 6 - Desarrollo de una base de datos

El proyecto consistió en el diseño y desarrollo de una base de datos utilizando diferentes herramientas especializadas. Inicialmente, se realizó la planificación de la estructura de la base de datos, identificando las entidades, atributos y relaciones necesarias para organizar la información de manera adecuada.

Posteriormente, se elaboró un diagrama entidad-relación (ER) utilizando Workbench, lo que permitió visualizar de forma clara la estructura lógica de la base de datos. A partir de este diseño, se generó el script correspondiente para la creación de la base de datos y sus respectivas tablas.

Finalmente, se procedió a la creación de las tablas en el sistema gestor de bases de datos, seguido de la inserción de registros para comprobar su funcionamiento. Se realizaron pruebas para verificar la correcta relación entre los datos y asegurar la integridad de la información almacenada.

Objetivos:

  • Diseñar una base de datos estructurada mediante un diagrama entidad-relación que represente correctamente la información.
  • Crear e implementar la base de datos utilizando scripts y herramientas especializadas.
  • Verificar el funcionamiento de la base de datos mediante la inserción y validación de registros.

Este proyecto me permitió comprender de manera más clara la organización y administración de bases de datos dentro de un entorno computacional. Aprendí la importancia de estructurar correctamente la información para facilitar su almacenamiento y consulta.

También adquirí conocimientos sobre la elaboración de diagramas entidad-relación, identificando correctamente entidades, atributos y relaciones. Esto me ayudó a entender cómo se modela una base de datos antes de su implementación.

Además, desarrollé habilidades prácticas en el uso de herramientas como Workbench, así como en la creación de tablas, inserción de datos y verificación de su funcionamiento. Este proceso fortaleció mi capacidad para manejar información de forma organizada y eficiente.
